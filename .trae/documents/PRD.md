# 产品需求文档（PRD）— 硬核媒体云仓库

## 1. 产品概述

基于高端健身工作室「专业、硬核、归属感」美学语言打造的媒体文件管理系统。以纯黑底色 + 金属银文字 + 霓虹橙（#FF6B00）强调色构建硬核暗黑主题，融合胶片颗粒纹理、毛玻璃组件与非线性缓动动效，在视觉上传递力量与质感；功能上提供多类型文件存储、预览、批量操作、班级/团队协作与细粒度权限控制，服务于校园/团队场景下的媒体资产协作。

- **目标用户**：校园班级成员、团队协作用户、系统管理员
- **核心价值**：在硬核专业视觉氛围中完成高效的媒体文件协作与权限治理

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 身份码 `User` 注册 | 查看/上传/编辑删除自己的文件、创建文件夹、加入团队 |
| 管理员 | 身份码 `Admin` 注册 | 全部 9 种权限，含管理用户、管理所有文件夹、团队管理 |

### 2.2 功能模块

1. **认证页（Auth）**：登录 / 注册 / 忘记密码（每月限 3 次）
2. **主页（Home）**：文件与文件夹网格/列表、上传、搜索筛选、批量操作、面包屑导航
3. **预览弹窗（PreviewModal）**：图片缩放旋转、音频播放、文档/压缩包下载提示
4. **团队面板（TeamPanel）**：创建团队、申请加入、审批、踢出成员、团队文件夹
5. **团队聊天（TeamChat）**：独立频道、2 分钟撤回、未读提示
6. **管理员面板（AdminPanel）**：用户列表、9 种权限逐项开关、注销账号

## 3. 核心流程

### 3.1 文件上传与预览流程

用户登录后进入主页 → 拖拽文件至上传区 → 后端 multer 接收并写入 uploads/ → 元数据存入 files.json → 前端刷新列表 → 点击文件卡片打开预览弹窗 → 图片支持缩放/旋转/键盘切换，音频内置播放器，文档/压缩包提供下载。

### 3.2 团队文件夹访问控制流程

管理员创建团队 → 用户发送加入申请 → 团队创建者审批 → 通过后成为成员 → 管理员创建团队文件夹（绑定团队）→ 所有人可见文件夹卡片 → 非成员点击弹出「无权限」提示 + 申请按钮 → 成员可进入访问。

### 3.3 权限校验流程

每次请求 → JWT 中间件解析 token → 从 users.json 实时读取权限 → 路由级权限中间件校验对应权限（view/upload/edit_own/edit_all/delete_own/delete_all/folder_create/folder_manage_all/manage_users）→ 通过则执行，否则返回 403。

```mermaid

    "用户登录" --> "JWT 签发"
    "JWT 签发" --> "访问资源"
    "访问资源" --> "权限中间件实时读取"
    "权限中间件实时读取" --> "权限校验"
    "权限校验" -->|"通过"| "执行操作"
    "权限校验" -->|"拒绝"| "返回 403"
    "执行操作" --> "更新 JSON 数据"
```

## 4. 用户界面设计

### 4.1 设计风格（融合高端健身工作室美学）

- **主色**：纯黑 `#000000`、深灰 `#0A0A0A`、`#141414`
- **强调色**：霓虹橙 `#FF6B00`（CTA、激活态、强调元素）
- **文字色**：金属银 `#E5E5E5`、`#A0A0A0`
- **字体**：标题使用粗体无衬线（力量感），正文使用紧凑无衬线（高信息密度），最小留白
- **按钮风格**：毛玻璃质感（backdrop-filter）+ 霓虹橙强调，CTA 按钮带柔和呼吸脉冲
- **布局风格**：卡片式网格 + 顶部导航，高信息密度，最小留白
- **图标风格**：lucide-react 线性图标，金属银描边，hover 转霓虹橙
- **纹理**：胶片颗粒覆盖层（grain overlay）增强质感，背景漂浮 3D 流体光晕球
- **动效**：cubic-bezier 非线性缓动，交错淡入 + 向上位移（stagger reveal），卡片 3D 鼠标跟随倾斜 + 聚光灯追踪，悬停渐变边框流动，点击波纹扩散，光标追踪光晕，Logo/文件夹图标呼吸缩放

### 4.3 响应式

- 桌面优先设计，网格视图自适应列数（最小 200px 卡片宽度）
- 移动端适配：顶部导航折叠、网格单列、聊天面板全屏侧滑
- 触摸优化：卡片拖拽支持触摸事件，预览弹窗支持手势缩放

### 4.4 动效细节（对应健身工作室交互语言）

- **入场动画**：页面加载交错淡入 + 向上位移（stagger reveal），对应「Section reveals use staggered fade + slight upward translate」
- **卡片悬停**：3D 鼠标跟随倾斜 + 聚光灯追踪，对应「Coach cards flip on hover」
- **CTA 脉冲**：上传/确认按钮柔和呼吸脉冲，对应「CTA pulses softly」
- **颗粒视差**：胶片颗粒覆盖层随滚动轻微漂移，对应「grain-texture parallax drifts」
- **骨架屏**：加载中骨架脉冲，对应「skeleton placeholders」
- **震动/弹跳反馈**：错误震动、成功弹跳，对应 hardcore motivating vibe
