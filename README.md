# 北京中学云仓库

基于 React + TypeScript + Tailwind CSS + Vite 的媒体文件管理系统，支持多类型文件存储、预览、批量操作、班级/团队协作以及细粒度权限控制。

## 技术栈

- **前端**: React 18 + TypeScript + Tailwind CSS + Vite
- **后端**: Express 4 + TypeScript + multer + archiver
- **状态管理**: Zustand
- **认证**: JWT + bcryptjs
- **存储**: 文件系统 + JSON 元数据（无数据库依赖）

## 功能特性

### 文件管理

- **5 种文件类型**，支持上传：
  - **视频**: MP4, WebM, MOV, AVI, MKV, FLV, WMV, M4V, 3GP, TS, MPEG, MPG
  - **图片**: JPG, PNG, GIF, WebP, SVG, BMP, TIFF, AVIF, HEIC, HEIF
  - **音频**: MP3, WAV, OGG, FLAC, AAC, M4A, WMA, MID, MIDI
  - **文档**: PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX, TXT, CSV, RTF
  - **压缩包**: ZIP, RAR, 7Z, TAR, GZ
- **批量上传**：支持多文件队列管理和逐个命名
- **文件预览**：
  - 图片：缩放、拖拽、旋转、前后切换、键盘快捷键
  - 音频：内置播放器
  - 文档/压缩包：下载按钮提示
- **文件移动**：拖拽文件卡片到文件夹卡片即可移入
- **单个下载** 与 **批量下载**（ZIP 打包）
- **单个删除** 与 **批量删除**
- **文件重命名**
- **搜索与类型筛选**（全部/视频/图片/音频/文档/压缩包）
- **网格视图** 与 **列表视图** 双模式切换

### 文件夹管理

- 创建文件夹（有权限控制）
- 文件夹重命名（普通用户可重命名自己创建的文件夹，管理员可重命名任意文件夹）
- 文件夹删除（需要文件夹密码认证，普通用户仅能删除自己的文件夹）
- 文件夹密码保护（管理员可设置/修改密码，每位管理员只能管理自己设置的密码）
- 面包屑导航，支持层级跳转
- 点击顶部 Logo 区域一键返回根目录

### 班级 / 团队系统

- 管理员可创建团队（每人最多 3 个）
- 用户可向团队发送加入申请，等待创建者审批
- 团队管理员可通过或拒绝申请，将成员踢出团队
- **团队文件夹**：管理员创建团队文件夹后，所有人可见，但仅团队成员可访问
- 非团队成员点击团队文件夹会提示「非团队人员无权限查看」并显示申请按钮

### 团队聊天

- 每个团队拥有独立的聊天频道
- 发送的消息可在 **2 分钟内撤回**（撤回后显示「消息已撤回」）
- **未读消息提示**：顶部用户按钮右上角显示黄色圆点，打开聊天后自动标记为已读

### 用户与权限系统

- **注册 / 登录**（通过身份码区分管理员 / 普通用户）
- JWT 认证，权限每次请求均从数据库实时读取，避免权限变更后延迟生效
- **忘记密码**：点击忘记密码可设置新密码，每个账号每月最多重置 3 次
- **细粒度权限**（9 种）：
  - `view` — 查看文件
  - `upload` — 上传文件
  - `edit_own` — 编辑自己的文件（重命名）
  - `edit_all` — 编辑所有文件
  - `delete_own` — 删除自己的文件
  - `delete_all` — 删除所有文件
  - `folder_create` — 创建文件夹
  - `folder_manage_all` — 管理所有文件夹（删除 / 加密）
  - `manage_users` — 管理用户账号
- 管理员账号管理：查看所有用户、逐项开关权限、注销用户账号
- 用户可注销自己的账号

## UI / 交互体验

- **视觉风格**：硬核暗黑主题 — 纯黑背景 + 金属银文字 + 霓虹橙（#FF6B00）强调色
- **颗粒纹理**：胶片颗粒覆盖层，增强质感
- **毛玻璃组件**：卡片、按钮、输入框均使用 backdrop-filter 玻璃质感
- **非线性缓动动画**：cubic-bezier 非线性缓动曲线，含弹性/流体/弹簧等多种过渡
- **卡片动效**：
  - 3D 鼠标跟随倾斜 + 聚光灯追踪
  - 悬停渐变边框流动
  - 点击波纹扩散
- **入场动画**：交错淡入 + 向上位移（stagger reveal）
- **3D 流体光晕球**：背景漂浮光晕装饰
- **光标追踪光晕**：跟随指针的柔光
- **呼吸缩放**：Logo 与文件夹图标的呼吸感缩放
- **动画反馈**：震动（错误）、弹跳（成功）、骨架屏（加载中）
- **渐变边框**：弹窗与容器的发光边框流动效果
- **支持键盘快捷键**：图片预览中的方向键切换 / ESC 关闭等

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
# 启动后端 API（端口 3001）
npx tsx api/server.ts

# 启动前端 Vite（端口 5173）
npx vite --host
```

打开浏览器访问：**http://localhost:5173/**

### 构建生产版本

```bash
npm run build
```

## 数据存储

项目使用 JSON 文件作为数据存储（无数据库依赖）：

| 路径 | 内容 |
|---|---|
| `data/users.json` | 用户数据（含密码哈希、权限、密码重置记录） |
| `data/files.json` | 文件元数据（5 种类型的识别与分类） |
| `data/folders.json` | 文件夹数据（含密码哈希、团队 ID、设置者 ID） |
| `data/teams.json` | 团队数据（成员、待审批、团队文件夹） |
| `data/chats.json` | 团队聊天消息（含撤回状态） |

上传的文件实际存储在 `uploads/` 目录下。

## 权限说明

### 用户注册

- 注册时输入身份码：
  - `Admin` 身份码 → 管理员账号，拥有全部权限
  - `User` 身份码 → 普通用户账号，仅能操作自己的文件和文件夹

### 权限能力矩阵

| 权限 | 普通用户默认 | 管理员默认 | 说明 |
|---|---|---|---|
| `view` | ✅ | ✅ | 查看文件列表和下载 |
| `upload` | ✅ | ✅ | 上传文件到任意目录 |
| `edit_own` | ✅ | ✅ | 重命名自己上传的文件 |
| `edit_all` | ❌ | ✅ | 重命名任意文件 |
| `delete_own` | ✅ | ✅ | 删除自己上传的文件 |
| `delete_all` | ❌ | ✅ | 删除任意文件 |
| `folder_create` | ✅ | ✅ | 创建文件夹 |
| `folder_manage_all` | ❌ | ✅ | 删除/加密任意文件夹 |
| `manage_users` | ❌ | ✅ | 管理其他用户的权限和账号 |

管理员可在「账号管理」面板中为任何用户逐项开关上述 9 种权限，或注销用户账号。

## 团队文件夹与访问控制

- **团队文件夹**由管理员通过「班级/团队」面板创建，并绑定到某个团队
- 团队文件夹对所有人在文件列表中**可见**，但仅团队成员可**点击进入**
- 非团队成员点击会弹出提示，并提供「申请加入」按钮
- 申请加入需团队创建者审批通过
- 非团队成员对团队文件夹无任何操作权限（包括重命名、加密等）
- 团队创建者可将任意成员踢出团队，踢出后该成员失去团队文件夹访问权限
